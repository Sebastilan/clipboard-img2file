## 根因分析

**1. 进程被 Windows 强杀**

崩溃时间点（10:27~10:32）有密集的 **Kernel-Power ID=105** 电源状态切换事件，说明笔记本在进行电源管理（Modern Standby 或睡眠过渡）。Windows 在这些状态下会强制终止后台进程——连 `finally` 块都没机会执行，日志里没有任何退出记录。

**2. Task Scheduler 无法自动重启**（核心问题）

`launcher.vbs` 第 15 行：
```vbs
WshShell.Run cmd, 0, False   ← False = 不等待子进程
```

VBS 启动 PowerShell 后立即退出返回 0 → Task Scheduler 认为任务"成功完成" → 状态变 "Ready"。后来 PowerShell 被杀时，Task Scheduler 已经不管了——`RestartCount=999` 形同虚设。

## 修复方案

把 `False` 改成 `True`，让 VBS 等待 PowerShell 进程。这样：
- Task Scheduler 保持 "Running" 状态
- PowerShell 被杀 → VBS 也结束 → 返回非零退出码
- RestartOnFailure 生效，1 分钟内自动重启
